# SecureInChat Blog

Privacy, encryption and digital security content site for secureinchat.com.

## Deployment

This repository is prepared for Cloudflare Pages or GitHub Pages.

### Cloudflare Pages (recommended)
1. Log in to Cloudflare Dashboard
2. Go to Workers & Pages → Create application → Pages → Connect to Git
3. Select this repository (Paul30028/secureinchat-blog)
4. Build settings: Framework preset = None, Build command = (empty), Output directory = /
5. Save and Deploy
6. In Custom domains, add `blog.secureinchat.com` or the path you prefer

After connection, every push to main will auto-deploy.

Content is continuously generated for ad monetization (AdSense / similar networks).
